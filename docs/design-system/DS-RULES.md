# Beeline Business — B2B маркетплейс (ИП / самозанятые)

Визуальный стиль зафиксирован. Любой новый экран рисуется на этой системе, без изобретения новых цветов, шрифтов и отступов.

## Как начинать новый экран
1. Скопировать `Screen Template.dc.html` → `<Название экрана>.dc.html` (`copy_files`), дальше править копию.
2. Блок `<helmet>` из шаблона переносить **без изменений** — это единственный источник токенов.
3. Сниппеты компонентов (кнопки, карточки, поля, бейджи, строки таблиц, планы) брать из `DS-BASE.md`.
4. Эталон всех состояний и экранов — `Beeline Business DS.dc.html`. Новые компоненты сначала добавляются туда, потом используются на экранах.

## Правила стиля (не нарушать)
- Фон страницы `--bg` (тёплый off-white), поверхности `--surface` (белый). Чистый белый фон страницы не использовать.
- Карточка по умолчанию: `background:var(--surface);border:var(--card-border);box-shadow:var(--card-shadow)` (тени нет). Тень — только hover и оверлеи.
- Hover карточки: `border-color:var(--border-strong);box-shadow:var(--shadow-sm)`. Без подъёма и масштабирования.
- Акцент действия — только чёрный `--accent`. Синий не используется. Жёлтый `--brand` — бренд-маркер (лого, один чип), не кнопка.
- Одна primary-кнопка на экран.
- Serif (`--font-serif`) — заголовки разделов и метрики. Цены и суммы — sans 600 + `font-variant-numeric:tabular-nums`. Serif для цен не использовать.
- Статусы — цветной текст + точка 6px. Крупные залитые плашки не использовать; тонированный фон (`--*-bg`) — только для одной полосы-уведомления на экран.
- Иконки — линейные, `fill="none"`, `stroke="currentColor"`: stroke 1.4 на 15–16px, 1.25 на 20–28px. Никаких залитых и цветных иконок, никаких эмодзи.
- Отступы кратны 4: внутри карточек 20–28px, между блоками 32–72px. Группы элементов — flex/grid + `gap`.
- Кнопки и чипы — `white-space:nowrap`, высота `--row-h` (44px) или 36–38px в плотных строках.
- Радиусы только из токенов: `--r-sm` поля и кнопки, `--r-md` блоки, `--r-lg` карточки, `--r-pill` бейджи.
- Минимальные размеры: body 15px, подписи 12px, цель нажатия 44px в мобильных макетах.
- Тексты на русском, деньги в тенге: `7 900 ₸`, узкий пробел не нужен, разряд — обычный пробел.

## Тон копирайта
Коротко и по делу, без маркетингового пафоса. В плитке каталога — одно предложение о пользе, без цены и кнопки. Условия и сноски — мелким `--ink-3`.

## Файлы
- `Beeline Business DS.dc.html` — библиотека: токены, компоненты, экраны (каталог, заявка, тариф, партнёры, планы, личный кабинет).
- `DS-BASE.md` — helmet-блок и сниппеты для копирования.
- `Screen Template.dc.html` — скелет нового экрана (топбар + сайдбар + рабочая область).
