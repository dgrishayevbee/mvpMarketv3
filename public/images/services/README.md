# Иконки услуг — сдержанная версия

Шесть иконок под карточки услуг в языке маркетплейса: графит как база, объект
белым объёмом и ровно одна жёлтая деталь на иконку. Никаких цветных плиток —
цвет работает только как акцент, как в остальном интерфейсе.

| Файл | Карточка | Объект | Жёлтая деталь |
| --- | --- | --- | --- |
| `svc-acquiring` | Эквайринг | карта и QR-код | чип на карте |
| `svc-accounting` | Онлайн-бухгалтерия | калькулятор | клавиша «=» |
| `svc-pbx` | Виртуальная АТС | телефонная трубка | сигнал |
| `svc-edo` | ЭДО и подпись | документ | подпись |
| `svc-antifraud` | Антифрод для сайта | щит с галочкой | значок проверки |
| `svc-ads` | Реклама в поиске | строка поиска и столбцы | старший столбец |

## Три варианта

```
dark/    графитовая плитка 80×80 — как чёрные квадраты сейчас на сайте
light/   светлая плитка, если ряд нужно облегчить
plain/   объект графитом без плитки, прозрачный фон — для мелких мест
```

`dark` — прямая замена: плитка уже внутри картинки, свой фон у контейнера
можно убрать. `plain` подходит для нижней строки карточки («Платежи»,
«Бухгалтерия») и для списков — он тёмный, поэтому на белом читается.

Смешивать `dark` и `light` в одном ряду не стоит.

```
svg/dark · svg/light · svg/plain   исходники, для сайта лучше они
png/ · png2x/                      растр 80×80 и 160×160, прозрачный фон
preview.png                        оба варианта плиток в вёрстке карточек
```

## Как подставить

1. Скопируйте нужную папку в `public/images/services/`.
2. В данных услуги укажите путь, например
   `imageUrl: '/images/services/svc-acquiring.svg'`.
3. Размер в вёрстке прежний, 56×56. Для варианта `dark` уберите чёрный фон у
   плитки — иконка приносит свой, со скруглением 22 из 80 (то есть ~15 px при
   56 px).
